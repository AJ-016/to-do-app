# My Todo App 📝
A lightweight, local-first Progressive Web App (PWA) built to manage tasks efficiently without needing a backend.

## Features
* Persistent Storage: Saves your tasks automatically to your browser's local storage.
* Offline Support: Works offline thanks to built-in Service Worker caching.
* Task Management: Add, edit, delete, and filter tasks (All/Active/Completed).
* Theme Toggle: Switch between clean light and dark modes.
* Task Counter: Keep track of how many items remain.

## Setup & Deployment
* Local Development: Simply clone this repository and open index.html in your browser.
* Live Demo: You can access the live version of this app here: [click to open the live demo](https://aj-016.github.io/to-do-app/).
* Deploy Your Own: Since this is a static site, you can host it for free on GitHub Pages by enabling it in your repository settings under the "Pages" tab.

## How to Use
* Add Task: Type in the input field and click "Add" or press Enter.
* Complete/Active: Check the box to mark a task as done; use the filter buttons to sort your view.
* Clear: Use the "Clear Completed" button to remove all finished tasks at once.
* Edit: Click the "Edit" button on any task to update its text.

## Tech Stack
* Frontend: HTML5, CSS3, Vanilla JavaScript.
* Architecture: Local-first, PWA (Manifest.json & Service Workers).
